# MemoFlow Models

Hosted CoreML models downloaded in-app by [MemoFlow](https://memoflow.app).

## whisper-hindi2hinglish-apex

[Oriserve/Whisper-Hindi2Hinglish-Apex](https://huggingface.co/Oriserve/Whisper-Hindi2Hinglish-Apex) converted to WhisperKit CoreML format (see the app repo's `Scripts/convert-hinglish-model.sh` for the reproducible conversion). Published as release assets; the app downloads and verifies them on demand.
